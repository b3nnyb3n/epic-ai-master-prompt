## GitHub Pages deployment

The public repository is **https://github.com/b3nnyb3n/epic-ai-master-prompt**. Its root contains the complete source files and the mobile-friendly `index.html` page.

To make the HTML page available as a public website:

1. In this repository select **Settings → Pages → Build and deployment → Deploy from a branch**; select `main` and `/(root)`, then save.
2. Check the GitHub Pages deployment status and open the confirmed live website on a phone to test both Copy buttons.
3. Add that website URL to TikTok's profile website field if your account permits it; direct viewers to it in the caption.

The GitHub repository itself displays the source files publicly even before Pages is enabled.
